### 2. 기술 스택 검토 (Technology Stack Review)

스마트팜 시스템의 요구사항(실시간 데이터 수집, 장기 데이터 저장, 원격 제어)을 고려하여 다음 기술 스택을 제안합니다.

#### 2.1. IoT 및 엣지 레이어 (Sensing & Actuation)
*   **센서/액추에이터:** 아두이노(Arduino) 또는 라즈베리 파이(Raspberry Pi) 기반의 마이크로컨트롤러 및 센서 모듈 사용.
*   **통신 프로토콜:** **MQTT** (경량성 및 실시간 메시징에 최적), Modbus (장비 연동 시).
*   **장점:** 저전력, 비용 효율적이며, 현장 장비와의 직접적인 물리적 제어에 용이합니다.

#### 2.2. 데이터 파이프라인 및 백엔드 (Data Pipeline & Backend)
*   **데이터 수집/처리:** **AWS IoT Core** 또는 **Google Cloud IoT**를 사용하여 MQTT 메시지를 수신하고, **Node-RED** 또는 **Python (Flask/Django)**을 사용하여 엣지 데이터를 처리합니다.
*   **데이터베이스:** 시계열 데이터(Time-Series Data)의 특성을 고려하여 **InfluxDB** 또는 **PostgreSQL (TimescaleDB 확장)**을 사용하여 센서 데이터를 저장합니다.
*   **장점:** 시계열 데이터 관리에 특화되어 있으며, 대용량 데이터의 효율적인 저장이 가능합니다.

#### 2.3. 애플리케이션 및 API 레이어 (Application & API)
*   **API:** 모든 데이터와 설정에 접근하기 위한 RESTful API를 구축합니다. (Python의 FastAPI 또는 Node.js의 Express 권장)
*   **프론트엔드:** 웹 대시보드(Dashboard) 구현을 위해 **React** 또는 **Vue.js**를 사용하여 실시간 데이터 시각화 및 원격 제어 인터페이스를 구축합니다.

### 3. 아키텍처 초안 (Preliminary Architecture Draft)

제안하는 아키텍처는 **IoT 엣지 -> 클라우드 백엔드 -> 사용자 인터페이스**의 3계층 구조를 따릅니다.

**[시스템 아키텍처 다이어그램 (개념도)]**

1.  **엣지 레이어 (Edge Layer - 현장)**
    *   **구성 요소:** 센서 (온도, 습도, 토양), 액추에이터 (펌프, 팬), 마이크로컨트롤러 (ESP32/RPi).
    *   **역할:** 물리적 환경 데이터를 측정하고, 제어 명령을 수신하여 액추에이터를 구동하며, 측정된 데이터를 MQTT를 통해 클라우드로 전송합니다.

2.  **클라우드/백엔드 레이어 (Cloud/Backend Layer)**
    *   **구성 요소:** MQTT 브로커 (AWS IoT Core), 데이터베이스 (InfluxDB), API 서버 (FastAPI).
    *   **역할:** 엣지에서 수집된 실시간 데이터를 수신, 저장, 분석하고, 사용자 요청에 응답할 API를 제공합니다.

3.  **프레젠테이션 레이어 (Presentation Layer - 사용자)**
    *   **구성 요소:** 웹 대시보드 (React/Vue.js), 모바일 앱 (선택 사항).
