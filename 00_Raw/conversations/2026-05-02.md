최근 스마트팜 분야의 핵심 트렌드는 **데이터의 정밀성, 연결성(Connectivity), 그리고 에너지 효율성**입니다.

*   **Edge Computing:** 각 하우스 내에서 데이터 수집 및 1차 판단(예: 온도 초과 시 즉시 제어)을 수행하여 클라우드 서버 부하를 줄이고 반응 속도를 극대화합니다.

| :--- | :--- | :--- | :--- |
| **PLC (Programmable Logic Controller)** | 산업 환경에 최적화, 높은 안정성 및 신뢰성, 복잡한 시퀀스 제어에 강함 | 초기 비용 높음, 프로그래밍 학습 곡선 존재 | 대규모 시설, 정밀한 입출력(I/O) 제어 (냉난방기, 펌프 등) |

3.  **액추에이터 제어:** 목표 달성을 위해 측창 개폐 모터 또는 환기 팬을 구동하는 액추에이터를 제어합니다.
    *   **솔루션:** 측창에는 **서보 모터** 또는 **스테퍼 모터**를 사용하여 정밀한 개폐 각도를 제어하며, 이는 RPi 또는 PLC의 디지털 출력(Digital Output)을 통해 제어됩니다.

## 스마트팜 5동 통합 제어 시스템 아키텍처 설계

제공된 기술 동향 리포트와 사용자 요구사항(5동 하우스, 관비기/측창 자동/수동 제어)을 바탕으로, 실시간 데이터 수집, 엣지 컴퓨팅 기반 제어, 클라우드 기반 데이터 파이프라인을 통합한 전체 시스템 아키텍처를 설계합니다.

### 1. 시스템 개요 및 핵심 구성 요소

본 시스템은 **엣지 컴퓨팅(Edge Computing)**을 통해 현장(하우스)에서 실시간 제어를 수행하고, **클라우드(Cloud)**를 통해 데이터 분석 및 원격 모니터링을 담당하는 3계층 아키텍처를 채택합니다.

| 계층 | 역할 | 핵심 기술 | 목표 |
| :--- | :--- | :--- | :--- |
| **Layer 1: Sensing & Actuation (현장 제어)** | 물리적 환경 측정 및 제어 실행 | IoT 센서, 마이크로컨트롤러 (RPi/ESP32), 액추에이터 | 실시간 환경 모니터링 및 자동 제어 루프 실행 |
| **Layer 2: Edge Processing (게이트웨이)** | 데이터 집계, 1차 제어 로직 실행, 통신 관리 | MQTT Broker, Edge Gateway (RPi 기반), 로컬 DB | 데이터 전처리 및 지연 없는 현장 제어 |
| **Layer 3: Cloud & Application (데이터/UI)** | 장기 데이터 저장, 분석, 사용자 인터페이스 제공 | AWS/GCP/Azure, Time Series DB (InfluxDB), Web API | 중앙 집중식 모니터링 및 원격 제어 인터페이스 |

---

### 2. 하드웨어 상세 설계 (Hardware Specification)

5동 하우스 각각에 대해 독립적인 제어 모듈을 구축하며, 통신 효율성을 위해 LoRaWAN 또는 Zigbee 기반의 메시 네트워크를 활용합니다.

#### 2.1. 하우스별 제어 노드 (Edge Node)
각 하우스(3중 비닐 하우스)는 독립적인 **엣지 게이트웨이**로 구성됩니다.

*   **제어기:** Raspberry Pi 4 (또는 ESP32 기반의 저전력 MCU)
    *   **역할:** 센서 데이터 수집, 로컬 제어 로직 실행, 클라우드 통신 관리.
*   **센서 모듈 (Input):**
    *   온/습도 센서: DHT22 또는 BME280 (고정밀)
    *   광량/온도 센서: MLX90614 (열화상 연동을 위한 기초 데이터)
    *   토양 수분 센서: 정전식 토양 센서 모듈
    *   대기 센서: 저전력 MEMS 기반 CO2/VOCs 센서
*   **액추에이터 모듈 (Output):**
    *   관비기 제어: 솔레노이드 밸브 또는 서보 모터 구동 펌프 제어
    *   측창 제어: DC 모터 구동을 위한 모터 드라이버 및 리미트 스위치
    *   환기 제어: DC 팬 또는 솔레노이드 댐퍼 제어

#### 2.2. 통신 및 네트워크 구성
*   **내부 통신 (센서 $\rightarrow$ 게이트웨이):** Zigbee 또는 LoRaWAN (저전력, 장거리 통신에 최적화)
*   **외부 통신 (게이트웨이 $\rightarrow$ Cloud):** MQTT 프로토콜 (경량성, 실시간 데이터 스트리밍에 적합)

---

### 3. 소프트웨어 및 데이터 파이프라인 설계

#### 3.1. 엣지 소프트웨어 (Local Control Logic)
*   **언어:** Python (데이터 처리 및 API 통신 용이성) 또는 C++ (실시간 제어 안정성)
*   **기능:**
    1.  **센서 퓨전:** 수집된 모든 센서 데이터를 시간 동기화하여 통합합니다.
    2.  **제어 알고리즘 (PID/Rule-Based):** 설정된 목표 온도/습도 및 외부 날씨 데이터(API 연동)를 기반으로 관비기 및 측창 제어 명령을 생성합니다.
    3.  **로컬 제어:** 설정값 도달 시, 액추에이터(밸브, 모터)에 직접 명령을 전송하여 자동 제어를 실행합니다.
    4.  **MQTT Publisher:** 처리된 환경 데이터 및 제어 명령을 클라우드 서버로 MQTT를 통해 발행합니다.

#### 3.2. 클라우드 데이터 파이프라인 (Data Pipeline)
1.  **데이터 수집 (Ingestion):**
    *   **Source:** 5개 엣지 게이트웨이에서 MQTT로 스트리밍되는 데이터.
    *   **Broker:** AWS IoT Core 또는 자체 구축 MQTT Broker.
2.  **데이터 저장 (Storage):**
    *   **시계열 데이터:** InfluxDB (시간 기반 데이터 분석에 최적)
    *   **메타데이터:** PostgreSQL (장비 정보, 사용자 설정, 이벤트 로그 저장)
3.  **분석 및 시각화 (Analysis & Visualization):**
    *   **API Layer:** RESTful API (Python/FastAPI 기반)를 구축하여 프론트엔드(웹/앱)가 데이터를 요청하도록 제공합니다.
    *   **Visualization:** Grafana 또는 자체 개발 대시보드를 사용하여 실시간 환경 상태, 히스토리 그래프, 제어 이력 등을 시각화합니다.
