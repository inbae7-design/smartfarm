# 🚀 2026년 5월 1일 업데이트 내용 요약 (스마트팜 대시보드 개선)

오늘 스마트팜 웹 대시보드 및 시스템에 적용된 주요 변경 사항입니다.

## 1. 🖥️ 대시보드 UI 개편 (프론트엔드)
> [!TIP]
> 기존의 단일 리포트 카드 레이아웃에서 출근/퇴근 리포트를 한눈에 볼 수 있도록 나란히 배치했습니다.

- **파일:** `src/App.jsx`
- **변경 사항:**
  - `latestReport` 단일 상태를 `dailyReports` 객체 상태로 변경하여 출근/퇴근 데이터를 분리 관리.
  - 대시보드 하단에 **"🌅 출근 리포트"**(에메랄드 색상)와 **"🌙 퇴근 리포트"**(블루 색상) 2개의 영역을 나란히(side-by-side) 배치하여 가독성 강화.
  - 리포트 데이터를 불러오는 API 호출 엔드포인트를 `/api/daily-reports`로 업데이트.

## 2. ⚙️ 리포트 로딩 로직 업데이트 (백엔드)
> [!NOTE]
> 프론트엔드의 UI 구조 변경에 맞춰 백엔드에서 출근 리포트와 퇴근 리포트 2가지를 모두 찾아서 반환하도록 수정했습니다.

- **파일:** `server.py`
- **변경 사항:**
  - 기존 `/api/latest-report` API를 `/api/daily-reports`로 변경.
  - `memory` 폴더의 리포트 파일들을 읽어와 수정 시간 기준 최신순으로 정렬.
  - 파일명에 `_morning.md`가 포함된 것을 출근 리포트로, 그렇지 않은 것을 퇴근 리포트로 구분하여 매핑 후 JSON 형태로 반환.

## 3. ⏰ 대시보드 자동 실행 기능 (자동화)
> [!IMPORTANT]
> 매일 아침 사용자가 직접 웹 브라우저를 켜지 않아도 자동으로 대시보드가 열리도록 편의 기능을 추가했습니다.

- **파일:** `open_dashboard.py` (신규 추가)
- **변경 사항:**
  - 파이썬의 `webbrowser` 모듈을 이용해 기본 브라우저에서 로컬 대시보드 주소(`http://localhost:5173`)를 자동으로 여는 스크립트 작성.
  - Windows 작업 스케줄러(Task Scheduler)를 활용하여 **매일 아침 8시**에 이 스크립트가 실행되도록 시스템 설정 완료.

## 4. 🗄️ Git 버전 관리 시작
- **변경 사항:**
  - `smartfarm-web` 폴더 내 프로젝트 파일들에 대해 **Initial Commit (초기 커밋)** 을 완료하여 Git 추적(Tracking) 상태로 변경.
  - 향후 코드 변경 사항 발생 시 손쉽게 변경 이력을 확인하고 복원할 수 있도록 설정됨.
