# 📋 작업 브리프

**원 명령:** 정리된 자료를 토대로 HTML형식의 웹 화면을 만들어줘

## 요약
스마트팜 자료를 기반으로 사용자가 원하는 HTML 형식의 웹 화면을 제작하는 작업입니다.

## 분배
- **💰 Business**: 스마트팜에 가장 중요한 KPI(온도, 수확량 등)와 비즈니스 목표를 기반으로 웹 화면에 표시할 핵심 데이터를 정의하고 우선순위를 설정
- **🎨 Designer**: 정의된 KPI와 목표에 맞춰 스마트팜 대시보드의 전체 레이아웃, 색상 팔레트, 그리고 시각적 디자인 컨셉(UI/UX)을 구체적으로 설계
- **💻 Developer**: Designer가 제시한 디자인 브리프와 데이터 구조를 바탕으로 실제 작동하는 HTML, CSS 코드를 작성하여 웹 화면을 구현
